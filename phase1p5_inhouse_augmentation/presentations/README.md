# `phase1p5_inhouse_augmentation/presentations/` — Phase 1.5 발표·보고 자료

본 폴더는 **Phase 1.5 (in-house augmentation, laser/corrosion/biphilic)** 의
발표·보고 자료 전용이다. Cross-phase 자료는 workspace 루트 `presentations/`.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `slides/` | 구두 발표 (학회, 세미나) |
| `slides/archive/` | 옛 버전, draft |
| `posters/` | 학회 포스터 |
| `reports/` | 서면 보고서 (지도교수, 기금) |
| `outreach/` | 보도자료, SNS |
| `conference_abstracts/` | 학회 abstract submission |

## 명명 규칙

```
slides/<YYYY>_<event>_<topic>/
  예: 2026_lab_seminar_phase1p5_intro/
      2026_IHMTC_phase1p5_cross_lab_validation/

reports/<YYYY>_<MM>_<source>_<type>.<ext>
  예: 2026_08_advisor_phase1p5_proposal.md
      2026_11_NRF_phase1p5_progress.docx
```
