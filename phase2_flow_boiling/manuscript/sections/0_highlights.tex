\begin{itemize}
\item Surface- and flow-conditioned PINN predicts ONB in subcooled forced convection.
\item Frozen pool-boiling surface encoder is transfer-learned to flow boiling ONB.
\item One-sided Hsu lower bound and reduced-pressure input embed boiling physics.
\item Test wall-superheat RMSE 1.77~K: about 2$\times$ better than classical correlations.
\item Single model spans 0.1--16~MPa and 0.35--9.5~mm with ensemble uncertainty.
\end{itemize}
